UPS / Battery status

Component reference for the Dashboard's existing "Power & RTC" card — not a new sidebar page.

Speculative — low priority, not on a milestone yet. See docs/research-ups-battery.md for the full writeup. This page exists to make one thing concrete: what the Power & RTC card's "Power source"/"Battery" rows actually look like once they're backed by real data, instead of the hardcoded UPS · plugged / 100% values 03-dashboard.html currently shows as a placeholder. It is not a new sidebar entry — the real implementation is two rows on the card that's already there.

No UPS detected

Row hidden entirely, not shown as "n/a" or zeroed out — same precedent as the Storage card hiding its RAID row when no array exists. Fabricating a "Power source: —" row on hardware with no UPS attached (the common case — this is an optional add-on, not stock EON/ONE hardware) would be a correctness bug, not an honest gap. Detection: presence of /dev/shm/upslog.txt, tailed the same way the original Python dashboard did — see the research doc for why this app can't yet own UPS polling itself.

What the underlying data actually looks like

# /dev/shm/upslog.txt — written by the separate, optional # "Argon Industria UPS" daemon (argononeupsd.py), not this app Power: Battery 45% # parsed as: first token (lowercased) — "battery" = on battery, # anything else (e.g. "ac") = charging/plugged. Second token is # the percentage. >99% while charging displays as "Plugged".
